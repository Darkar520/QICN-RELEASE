# Cycle 3 Semi-Blind Protocol

## Blindness level
Semi-blind.

## What the judge sees
- blind case IDs
- frozen trace artifacts
- threshold files
- blind pair definitions
- stress target definitions

## What the judge does not see before emitting decisions
- true case labels
- which case is the expected positive
- which case is the negative control
- which case is the near-miss
- the true substrate names behind the blind IDs

## Limitation
The judge still knows structural roles such as "single-case classification" and "pair equivalence task". This is not fully blind evaluation.

## Outcome
- Blind judgments were written first.
- Only then were labels revealed for interpretation.
