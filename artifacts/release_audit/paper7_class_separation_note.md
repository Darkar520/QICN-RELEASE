# Paper 7 Class Separation Note

The hardening pass added an explicit Class-Separation Diagnostics layer to prevent collapse between four distinct families:

- L_op: operational life
- C_op: inherited operational consciousness
- structural class membership
- S_op: operational subjecthood

## Main separations
- L_op = 1 does not imply C_op = 1: persistence, maintenance, history, and viability can be satisfied without the inherited six-invariant consciousness burden.
- L_op = 1 does not imply S_op = 1: subjecthood adds privileged continuity, self/non-self discrimination, self-model burden, and ownership coherence.
- C_op = 1 does not imply S_op = 1: consciousness remains insufficient for subjecthood unless subject-specific burdens are met selectively.
- Structural class membership is the organizing layer: it determines when transport, comparison, and near-miss diagnosis are legitimate and when they are invalid.

## Diagnostic additions
- positive class conditions
- near-miss classes
- negative controls
- explicit non-equivalence conditions
- invalid-comparison cases under descriptor mismatch or undeclared tolerance

This materially improves the paper because the classes now differ by criteria and failure geometry, not only by prose description.
