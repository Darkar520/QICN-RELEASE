# Paper 7 Failure and Misclassification Note

The hardening pass added a dedicated failure layer so that class membership is not overread from superficial runtime evidence.

## False-positive modes
- inert persistence mistaken for operational life
- complexity/connectivity mistaken for operational consciousness
- structured reactivity mistaken for operational subjecthood

## False-negative modes
- short traces underclassifying operational life
- signal poverty underclassifying subjecthood

## Cross-cutting distortions
- misclassification by complexity alone
- misclassification by residual proxy contamination
- knife-edge class-boundary ambiguity
- invalid class transport under descriptor mismatch

## Value of the new section
Each mode is now tied to mechanism, symptom, classificatory risk, and control or mitigation. This materially hardens the paper because it states not only what each class requires, but how the classification can fail even when the surface evidence looks strong.
