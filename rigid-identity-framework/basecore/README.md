# BaseCore Package

This folder contains the active BaseCore package of the Rigid Identity Framework.

## Source of Truth

- `BASECORE.tex`
- `core/sections/*`
- `core/canonical_core_references.bib`

`BASECORE.pdf` is the compiled artifact derived from that tree.

## Scope

BaseCore is the autonomous mathematical base layer. It selectively absorbs formal material from Papers 1-6 where theorem ownership belongs in the base package. Papers 7-9 remain downstream.

BaseCore does not prove phenomenality, metaphysical subjectivity, human equivalence, runtime instantiation, bridge admissibility, or external adjudication.

## Package Contents

- `BASECORE.*` build artifacts for the active release-facing base document
- `core/` for bibliography and section modules
- `core_meta/` for audit, normalization, verification, and editorial records

Compile from this folder when rebuilding the active base document.
