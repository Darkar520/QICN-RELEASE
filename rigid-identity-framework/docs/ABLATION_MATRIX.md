# Ablation Matrix v1

## Governance boundary

This document defines ablations, controls, rival comparisons, and downgrade/death rules. It does not certify external support, consciousness, phenomenality, identity transfer, or bridge-burden closure.

## Purpose

The matrix closes the missing roadmap artifact `docs/ABLATION_MATRIX.md` and converts ablations into pre-execution rules. It is not an executed ablation campaign. Every row below remains non-result-bearing until a frozen manifest, admissible dataset, exclusion log, and decision record exist.

## Non-negotiable execution rule

No row may be promoted from scaffold to evidence unless the run manifest is frozen before execution, the exclusion log is audited using non-semantic rules, and the downgrade rule is applied even when it weakens QICN.
