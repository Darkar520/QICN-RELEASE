# Operational Term Promotion Rules v1

## Governance boundary

This document governs claim language and promotion gates. It does not certify external support, consciousness, phenomenality, identity transfer, or bridge-burden closure.

## Rule

A term may move from metaphor to operational claim only when it carries an observable, a measurement slot, a negative-control suite, a rival model, and a death rule. A term may move from internal formal status to external support only after non-synthetic data and independent adjudication exist.

## Promotion ladder

| Level | Allowed status | Minimum requirements |
|---|---|---|
| metaphor_or_expository | non_claim | explicit metaphor marker; no theorem or prediction status |
| operational_scaffold | scaffold | observable, measurement slot, controls, death rule |
| formal_internal | internal_formal | definition/theorem label, dependency boundary, limitation/counterexample, registry link |
| synthetic_internal_executed | internal_synthetic | frozen manifest, deterministic report, adversarial controls, no external-support language |
| external_adjudicated | external_evidence_claim | non-synthetic dataset hash, independent decision record, signed or archived adjudication, reproducible runner output |

## Blocked terms

The following phrases must not be promoted to external or ontological claims inside the repository unless the stated gate is met.

| Term | Blocked until | Allowed use before gate |
|---|---|---|
| consciousness | external adjudication plus bridge-burden adjudication | negative boundary or future adjudication object |
| phenomenality | external adjudication plus bridge-burden closure | explicitly non-certified boundary |
| identity transfer | external adjudication plus non-branching identity protocol | not certified |
| proof of global atomicity | global theorem closes product-separator obstruction | not proved from weak premises |
| empirical support | external non-synthetic dataset and independent adjudication | absent/pending |
