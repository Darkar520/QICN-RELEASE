Lemma 1 (No global reconstruction from finite preservation). If π is not injective, then a finite
bridge certificate cannot by itself reconstruct X or prove any property that varies within a fiber
π −1 (y).
Proof. If π is not injective, there exist x1 ̸= x2 with π(x1 ) = π(x2 ) = y. Any estimator
G : Y → Z has the same value G(y) for both states. If a property P differs between x1 and x2 ,
no function of y alone identifies P . Therefore finite preservation of selected invariants does not
reconstruct the latent state or all latent properties.
