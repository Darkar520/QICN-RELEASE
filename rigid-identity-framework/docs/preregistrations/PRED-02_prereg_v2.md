# PRED-02 Preregistration v2

Status: frozen internal synthetic execution with seeded invariant simulator

## Boundary

This preregistration records an internal synthetic invariant-ablation protocol.
It is not empirical support, not external adjudication, and does not validate
consciousness, phenomenality, identity transfer, agency, moral status, or the
full QICN framework.

## Upgrade Over v1

Version 1 used fixed panel numbers. Version 2 generates pre/post certification
scores from a seeded invariant vector and a declared ablation manifest. This is
still synthetic, but it removes fiat certification values from the runner.

## Frozen Rule

- Freeze: `docs/preregistrations/PRED-02_freeze_v2.json`
- Target invariant: `Iint`
- Ambiguity threshold: `delta_amb = 0.05`
- Rupture threshold: `rho_rupture = 0.5`
- Negative controls: boundary ambiguous, sham ablation, noise-only

Support requires verified invariant loss, certification drop above
`delta_amb`, pre-ablation headroom above `delta_amb`, and relative rupture at
or above `rho_rupture`.
