# PRED-11 Preregistration v2

Status: frozen internal synthetic execution with seeded integration-loss simulator

## Boundary

This preregistration records an internal synthetic integration-loss protocol. It
is not empirical support, not external adjudication, and does not validate
consciousness, phenomenality, identity transfer, agency, moral status, or the
full QICN framework.

## Upgrade Over v1

Version 1 used fixed pre/post profiles. Version 2 derives certification from a
seeded pre-profile and a declared intervention manifest, and adds negative
controls for complexity loss, weak integration loss, and preserved complexity
without integration loss.

## Frozen Rule

- Freeze: `docs/preregistrations/PRED-11_freeze_v2.json`
- Integration loss boundary: `0.5`
- Complexity preservation epsilon: `0.02`
- Certification threshold: `0.5`

Support requires a large integration drop, preserved complexity, and
post-intervention certification below threshold. Complexity changes without
integration loss must fail the same support rule.
