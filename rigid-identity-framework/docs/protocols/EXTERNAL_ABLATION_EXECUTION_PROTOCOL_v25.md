# External Ablation Execution Protocol v25

Governance boundary: this protocol does not certify external support, consciousness, phenomenality, identity transfer, bridge-burden closure, or human mathematical review.

## Purpose

Ablation matrices are not evidence until executed. This protocol converts ablation rows from textual scaffolds into externally executable manifest obligations.

## Minimum executable ablation record

Each ablation must declare:

1. ablation ID and linked claim ID;
2. raw data hash and acquisition source;
3. preregistered exclusion rules;
4. target model and rival model manifests;
5. frozen thresholds with calibration status;
6. expected death-rule action if the ablation fails;
7. negative controls that must fail;
8. independent runner hash.

## Current v25 status

The framework contains architecture for ablations, but no external ablation record has been executed. All ablation-derived support claims remain blocked.
