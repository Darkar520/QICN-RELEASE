# External Session Zero Adjudication Protocol v23

## Governance boundary

This protocol defines an ingestion and adjudication path for future non-synthetic datasets. It does not certify external support, consciousness, phenomenality, identity transfer, or bridge-burden closure.

## Objective

Close the `blocked_no_runner` engineering gap without pretending that external evidence already exists. The runner accepts a manifest, validates preregistered exclusions, propagates noise, compares QICN against simple rivals under complexity penalty, and emits a downgrade-capable decision record.

## Required inputs before any external claim

1. Frozen preregistration hash.
2. Non-synthetic dataset hash and acquisition boundary.
3. Measurement points with `observed_delta`, `noise_floor`, `measurement_sigma`, `separator_id`, and `response_coordinate`.
4. Exclusion log with only preregistered non-semantic reasons.
5. Rival model registry binding.
6. Independent adjudicator identity or archived third-party execution record.

## Statistical rule

The adjudicator uses inverse-variance weighted deltas, a normal-approximation 95% confidence interval, and AIC-style complexity penalties. A result can support, weaken, or degrade a claim. No support verdict is admissible if the manifest is `synthetic_fixture`.

## Death rule

If a rival has lower AIC than QICN after admissible exclusions, the associated claim must receive a downgrade proposal. If a negative control reaches the support criterion, the criterion must be recalibrated or abandoned before any further promotion.

## Non-execution boundary

The included fixture is for runner testing only. It is synthetic and cannot be cited as external support.
