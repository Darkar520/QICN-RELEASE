# Real Rival Engagement Protocol v24

Governance boundary: This document does not certify external support, consciousness, phenomenality, identity transfer, or bridge-burden closure.

## Purpose

QICN must not compare only against weakened internal straw-rivals. A real external adjudication must specify at least one operational rival from the relevant literature or engineering task and implement its observable prediction on the same dataset.

## Rival families to instantiate

| Rival family | Minimum implementation obligation | QICN claim it can challenge |
|---|---|---|
| IIT-style integration proxy | Define a computable integration or irreducibility proxy on the same response graph; declare why exact $\Phi$ is or is not computable for the dataset. | Factorization gap / integration claims |
| GNWT-style ignition proxy | Define a global broadcast or ignition-like event statistic on the same time series. | Identity-channel lock and response-phase claims |
| Predictive-processing / active-inference proxy | Define prediction-error reduction, model evidence, or blanket-style conditional independence statistic. | History alignment and runtime binding claims |
| HOT/metacognitive proxy | Define confidence/reportability/meta-state statistics where the dataset supports them. | First-person or subjecthood-adjacent claims |
| Markov/memory rival | Define depth, training split, and held-out scoring rule. | Any trace-memory claim |

## Acceptance rule

A QICN claim may not be promoted from internal support to external candidate support unless the rival implementation is frozen before outcome inspection and run on exactly the same admissible records.

## Downgrade rule

If a simpler rival wins under the frozen penalty and exclusions, the associated QICN claim is downgraded to `weakened` or `open_burden` in a dry-run record pending human review.
